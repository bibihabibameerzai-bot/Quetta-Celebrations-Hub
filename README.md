# Quetta Celebrations Hub

An all-in-one platform built for Quetta to plan events, connect with local vendors, and order gifts without the back-and-forth on WhatsApp.

## Key Features
Vendor Finder - Search and filter vendors by service category
Booking Tracker - Check booking status: pending, confirmed, completed
Vendor Profiles - View vendor details, photos, reviews and services
Budget Planner - Calculate and manage event budget
Wedding Hub - Dedicated section for wedding vendors and packages
User Accounts - Register, login and manage profile and bookings
Admin Panel - Manage vendors, bookings and platform content
Gallery, Decor and Gifts - Browse event ideas and order products

## Tech Stack
Frontend: HTML5, CSS3, JavaScript
Backend: PHP
Database: MySQL - schema in /database folder
Server: Apache with .htaccess routing
